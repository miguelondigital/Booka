# frontend

Vue 3 + Vite + TypeScript client for Booka. See the [root README](../README.md) for setup,
data modes, and scripts.

```sh
npm run dev -w frontend      # Vite on :5173, proxies /api to :3000
npm run test -w frontend     # club store tests
npm run build -w frontend    # type-check + production build to frontend/dist
```
